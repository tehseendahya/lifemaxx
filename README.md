# lifemaxx

All-in-one health tracker with an AI coach — meals, lifting, cardio, and body metrics
in one place, on phone and laptop.

- Snap a photo of a meal, get a macro breakdown
- Log lifts in natural language ("bench 5x5 185"), track progressive overload
- Pull runs and rides from Strava
- Ask a coach questions about your own data, and get nightly push summaries
